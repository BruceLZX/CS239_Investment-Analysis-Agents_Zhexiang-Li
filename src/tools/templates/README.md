# Report template

`report_template.html` is the investment-analysis skill's report template, from
[BruceLZX/investment-analysis-skill](https://github.com/BruceLZX/investment-analysis-skill) (MIT) at commit
`fb5ae3466aa6e9391cd0f7195633de08c4e54936` (`templates/report_template.html`), with its Chinese text translated to
English and its structure, styles and script unchanged. `tools/report.py` fills its placeholders when a memo version
is saved.
